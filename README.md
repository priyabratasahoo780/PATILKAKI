## 📖 About The Project

**Patil Kaki Website Clone** is a pixel-perfect front-end replica of the popular Maharashtrian homemade snack brand's e-commerce website. This project was built as part of a web development learning journey to master core HTML5 and CSS3 concepts including layout design, responsive UI, and component-based styling.

The original brand brings authentic, traditional Indian homemade snacks like **Puranpoli, Bhajni Chakli, Besan Ladoo, and Dink Ladoo** right to your doorstep — and this clone faithfully recreates that warm, traditional, yet modern web experience.

---

## 🎯 Learning Objectives

This project was built to practice and strengthen the following concepts:

| Skill Area | Concepts Covered |
|---|---|
| 🏗️ **HTML Structure** | Semantic HTML5, DOM hierarchy, Forms & Navigation |
| 🎨 **CSS Styling** | Flexbox, Positioning, Box Model, Custom styling |
| 🖼️ **Image Handling** | CDN-based image hosting via Cloudinary |
| 📐 **Layout Design** | Multi-column layouts, Header/Footer patterns |
| 🔗 **Multi-page Navigation** | Anchor tags, relative linking between pages |
| 🧩 **Component Cloning** | Recreating real-world UI components |

## 🚀 How To Run Locally

No build tools or dependencies required! Just follow these steps:

```bash
# 1. Clone the repository
git clone https://github.com/priyabratasahoo780/PATILKAKI.git

# 2. Navigate into the project folder
cd PATILKAKI

# 3. Open the homepage in your browser
# Simply double-click index.html OR use Live Server in VS Code
```

> 💡 **Tip:** Use the **Live Server** extension in VS Code for the best development experience with real-time reloading.
